# GitHub Copilot Training 2024

=======

Automate the selected feature with GitHub Copilot at the page [http://the-internet.herokuapp.com] using Github Copilot plugin.
The folder views containing HTML files with the necessary elements that Copilot utilizes to identify the correct selectors.

## Getting Started

1. Clone repository
2. Create a branch following the naming pattern: your_short_username_automated_feature.
3. Automate the selected feature with GitHub Copilot using one of the following methods of work:
   - Use predefine framework (Cypress) with one example of test
     \the-internet\testCypress
   - Chose your favorite framework and start from the scratch
     \the-internet\testYourFarmework
4. Replace the placeholder time with your corresponding time spent automating steps.

| Step | What to do                                                         | Time Spent |
| ---- | ------------------------------------------------------------------ | ---------- |
| 1    | Use Copilot to generate test cases (BDD scenarios)                 | mins       |
| 2    | Verify the quality of the test cases                               | mins       |
| 3    | Use Copilot to create steps definitions to implement BDD scenarios | mins       |
| 4    | Verify the quality of the steps definitions                        | mins       |
| 5    | Use Copilot to create a Page Object                                | mins       |
| 6    | Verify the Page Object                                             | mins       |
| 7    | Run full test suite and verify the result                          | mins       |
| 8    | Verify the code and put it together in the repository              | mins       |
